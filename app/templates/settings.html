Settings

Library folder

Point this at the root folder that contains your Publisher/Series/... book folders (the same library you'd browse in Chaptarr or any file manager). This is the only thing that differs from one person's setup to the next.

Scan & index

Scan finds books on disk and files them under the right game (see app/data/games.json to edit how Series folders map to games). Index extracts text so the Library page's search box can find things inside the PDFs - it can take a while for a large library, and older scanned PDFs with no text layer will show as "not searchable".

OCR scanned books

{{ ocr_counts.pending }} scanned book(s) have no embedded text and are waiting for OCR; {{ ocr_counts.failed }} previous attempt(s) found nothing readable; {{ ocr_counts.ocr_searchable }} book(s) are searchable thanks to OCR so far. OCR only feeds this app's own search index - your PDF files on disk are never changed or duplicated. It's much slower than normal indexing (seconds per page, not per book), and the first run downloads EasyOCR's recognition models, so start with the test batch before committing to the whole library overnight.
